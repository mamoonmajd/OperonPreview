# OPERON — Direction 4.5 Website

This package is a refined static website aligned to the approved OPERON Direction 4.5 brand identity.

## Preview
Open `index.html` in a browser, or serve the folder with any static web server.

## Brand direction incorporated
- Warm limestone and paper backgrounds
- Jordanian red, olive, bronze, and charcoal palette
- Direction 4.5 interlocking four-principle mark
- Editorial typography and generous whitespace
- Notebook-inspired hero composition
- Subtle Tatreez geometry and paper texture
- Story-led homepage structure
- Accurate geographic placement for regional cities
- No hero video, blue AI graphics, corporate stock photography, or black-and-gold luxury styling

## Homepage order
Hero → Operon Perspective → Why Operon → Services → Industries → Transformation Method → Regional Presence → Experience → About → Contact → Footer
